Customer Churn Analysis

This project focuses on analyzing customer churn data to understand the key factors driving customer attrition. Using Python-based data analysis techniques, the project explores customer demographics, service usage patterns, and account information to generate actionable business insights.

Key Features:

Data Cleaning and Preprocessing
Exploratory Data Analysis (EDA)
Customer Segmentation Analysis
Churn Pattern Identification
Data Visualization and Business Insights

Tech Stack:

Python
Pandas
NumPy
Matplotlib
Jupyter Notebook

Key Insights:

Identified customer segments with higher churn rates.
Analyzed the impact of contract type, tenure, and services on churn behavior.
Generated visual insights to support customer retention strategies.
